# write-idea

Read and follow the installed `workflow.md` first.

Take input text describing the work or supplying intake input, such as an issue URL. File an Idea according to the required `new_idea_intake` setting:

- When the intake names a source reference resolver, store the input as the Idea's source reference.
- When the intake says to interview the Managing Intelligence, conduct the interview and write the description in the Idea's body.

Print the filed Idea's ID. Suggest `write-prd` as the next step.
