# Public GitHub Project

## Name

Public GitHub Project

## New Idea intake

Explain that public repos receive feature requests and bug reports through GitHub Issues. Check the confirmed code folders:

- If any is a public repo, use the `github` resolver at `~/.apiary/system/resolvers/github.md`.
- Otherwise, use the interview intake at `~/.apiary/system/intakes/interview.md`.

Write the resolved approach to `setting:new_idea_intake` in `<Project Folder>/.apiary/project_settings.md`.

## New Bug intake

Write the same intake choice to `setting:new_bug_intake` in `<Project Folder>/.apiary/project_settings.md`.
